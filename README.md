Workshop GitHub Day 1

CATATAN MATERI GIT & GITHUB
1. Prompt Engineering
- Cara membuat instruksi agar AI memberikan jawaban yang sesuai.
- Prompt = perintah atau pertanyaan yang diberikan kepada AI.
- Prompt yang baik harus jelas dan spesifik.

Struktur prompt:
1. Role = Peran AI.
2. Task = Tugas AI.
3. Context = Informasi tambahan.
4. Format = Bentuk jawaban.

2. Keuntungan Prompt Engineering
- Meningkatkan kualitas jawaban AI.
- Mengurangi jawaban yang tidak sesuai.
- Membuat jawaban lebih terarah.
- Memudahkan pengguna.

3. Pengertian Git
- Git adalah alat untuk mencatat perubahan pada file atau kode.
- Dibuat oleh Linus Torvalds pada tahun 2005.
- Berguna untuk melihat perubahan yang pernah dilakukan.

4. Pengertian GitHub
- GitHub adalah tempat menyimpan proyek secara online.
- Memudahkan kerja sama dengan orang lain.
- Menggunakan Git untuk mengelola perubahan proyek.

5. Perbedaan Git dan GitHub
- Git: Mengatur perubahan file.
- GitHub: Menyimpan proyek secara online.

6. Git Workflow
Ada 3 bagian penting:
1. Working Directory: Tempat mengerjakan file.
2. Staging Area: Tempat menyiapkan perubahan.
3. Git Directory: Tempat menyimpan data Git.

7. Perintah Dasar Git
Perintah	Kegunaan
git init	Membuat repository
git add .	Menambahkan perubahan
git commit -m "pesan"	Menyimpan perubahan
git clone "url"	Mengambil proyek dari GitHub
git push origin main	Mengirim proyek ke GitHub
git pull origin main	Mengambil perubahan dari GitHub

8. Git Setup
- Install Git.
- Buka Terminal atau CMD.
- Cek Git dengan git --version.
- Atur nama dan email pengguna.

9. VS Code Setup
- Install VS Code.
- Buka VS Code.
- Tekan Ctrl + Shift + P.
- Cari pengaturan Shell Command.
- Cek dengan code --version.

10. Menambahkan Repository
Ada 2 cara:
- git init = Membuat repository baru.
- git clone "url" = Mengambil repository dari GitHub.

11. Perintah Git Add
- git add --all = Menambahkan semua perubahan.
- git add -A = Sama dengan add --all.
- git add . = Menambahkan perubahan file.
- git add * = Menambahkan file baru dan yang diubah, bukan file yang dihapus.

12. SSH Key
- SSH Key digunakan untuk menghubungkan komputer dengan GitHub.
- Berguna untuk proses autentikasi atau verifikasi identitas.
- Dibuat menggunakan perintah ssh-keygen.

13. Mengecek Koneksi
- git --version = Mengecek Git.
- git config --global user.name = Mengecek nama.
- git config --global user.email = Mengecek email.
- code --version = Mengecek VS Code.
- ssh -T git@github.com = Mengecek koneksi GitHub.

14. Langkah Membuat Proyek
1. Install aplikasi AI.
2. Buat prompt untuk membuat aplikasi.
3. Masukkan proyek ke Git.
4. Simpan perubahan dengan commit.
5. Kirim proyek ke GitHub dengan push.
6. Lakukan perubahan.
7. Commit dan push kembali.

Tips menghafal perintah Git:
- init = Mulai.
- add = Tambahkan.
- commit = Simpan.
- push = Kirim.
- pull = Ambil.
- clone = Salin.
